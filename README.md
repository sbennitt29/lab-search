# Tiny Search Engine

Search a folder of text files and report matching lines with their filenames and line numbers.

The [course lab page](https://csci40.rtealwitter.com/topics/09_syntactic_sugar/lab.html)
has setup, requirements, examples, and submission instructions.

`search.py` contains the five functions to complete and their practice doctests.
`run_search.py` supplies file loading and terminal output.
`documents/` contains sample text files.
